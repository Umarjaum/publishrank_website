Cookie policy

Effective October 8, 2026 · Applies to the PublishRank website at publishrank.netlify.app.

Current website behavior

The current PublishRank website code does not set cookies or write visitor identifiers to localStorage or sessionStorage. Documentation search, navigation, expandable questions, and copy buttons operate in the current page without storing a visitor profile.

No analytics or advertising scripts are included in the site code. A cookie-consent banner is not used to claim consent for tracking that the site does not implement.

Hosting and infrastructure

Netlify delivers this website and may apply infrastructure-level security or delivery behavior. This policy describes the site code, not a guarantee about every provider response. Browser developer tools can be used to inspect cookies and storage associated with a visit.

External destinations

Embedded editorial photography loads from Unsplash’s image CDN even without following an external link. The site code does not use that photography to set visitor identifiers, but third-party delivery is governed by the provider’s practices. Photo-credit links open Unsplash destinations with their own policies.

Following a WordPress, Google, developer-profile, or other external link opens a service with its own cookie and storage practices. Those services are not controlled by PublishRank. Review their policies separately.

Browser controls and future changes

You can inspect, block, or clear cookies and website storage through your browser. If the project adds features requiring storage or tracking, this policy should be updated and any required consent mechanism implemented before those features are enabled.

For related information, read the privacy policy.
