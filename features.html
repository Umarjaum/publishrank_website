The complete publishing workflow

Twelve pillars.
One WordPress toolkit.

For bloggers, independent publishers, editorial teams and newsrooms. Source-verified means implemented in the bundled 2.9.67 PHP or editor code, not tested on every live installation. Optional controls require enabling; external integrations require configuration.

01

Article SEO Intelligence

Source-verified · v2.9.67

For bloggers and editors reviewing each story before publication.

Individual scores check headline and SEO title, description, keyphrase density, depth, headings, readability, featured images, bylines, dates and links. Review duplicate headlines, competing keyphrases, cornerstone content and actionable suggestions. Live editor re-analysis and progressive archive batches feed score cards and score distribution.

In WordPress: Post editor → PublishRank; PublishRank → SEO Score

Know the limits: Scores are editorial and technical checklists, not predictions of Google rankings.

02

Live SEO Preview

Source-verified · v2.9.67

For writers checking how an unsaved draft is represented.

Inspect desktop and mobile search snippets, title pixel width and character counts, description length, Website View, Facebook/LinkedIn and X cards. Review canonicals, robots, social images, HTML tags and syntax-highlighted, copyable JSON-LD. Automatic and manual refresh, validation warnings and a Rich Results Test link support review.

In WordPress: Block or Classic Editor → PublishRank Live Preview

Know the limits: Previews use PublishRank metadata logic and unsaved edits. Search engines and social platforms determine the final display.

03

Schema Suite

Source-verified · v2.9.67

For publishers connecting stories, authors and publication identity.

Build a connected JSON-LD graph with publisher, Person, WebSite, WebPage, article, image and breadcrumb entities. Choose Article, NewsArticle, ReportageNewsArticle, BlogPosting, LiveBlogPosting and supported technical or scholarly variants. Additional types include FAQPage, VideoObject, ImageGallery, AudioObject, PodcastEpisode, Event, Product, Recipe, Review and ItemList. Configure defaults, type-specific fields and author expertise.

In WordPress: PublishRank → Schema; per-content schema controls

Know the limits: Types depend on content and required fields. Every type is not emitted on every page, and schema does not guarantee rich results.

04

News & XML Sitemaps

Source-verified · v2.9.67

For independent publications and newsrooms maintaining discoverable archives.

Generate a sitemap index with post, page, public custom post-type, taxonomy, author, attachment, News, image and video providers. Endpoint configuration, aliases, readable stylesheets, sharding, caching and robots.txt discovery support operations. Set News publication identity, freshness, eligible types, exclusions, keywords and URL limits. Inspect XML, duplicate URLs, child references, eligibility and counts in Sitemap Health.

In WordPress: PublishRank → Sitemap Health; Settings

Know the limits: Sitemap inclusion does not guarantee crawling, indexing or Google News inclusion.

05

Image Optimization

Source-verified · v2.9.67

For teams preparing large editorial images and consistent social assets.

Review image dimensions, file sizes and recommendations, then create optimized copies with configurable maximum width, quality and WebP, JPEG or preserved format. The optimized file becomes the attachment file; the original remains on disk. Separately, optional social-image watermarking adds a logo with five positions, opacity, size and margins, caching derivatives while retaining originals.

In WordPress: PublishRank → Image Optimizer; Settings

Know the limits: Image processing depends on the WordPress image editor and server format support. Watermarking falls back to the original when processing is unavailable; it is separate from image optimization.

06

Traffic Guard

Source-verified · v2.9.67

For site owners managing anonymous frontend access by network or country.

Allow or block individual IPs and CIDR networks. Configure country blocks using Cloudflare country information from trusted proxy networks. Rules run locally, without a GeoIP API request or stored visitor IP addresses. Administrator, recovery, API, feed, robots and sitemap routes have exemptions.

In WordPress: PublishRank → Traffic Guard

Know the limits: Optional and disabled by default. Country rules require correct trusted-proxy configuration; missing or invalid country data is handled conservatively. This is request control, not a complete firewall, WAF or DDoS service.

07

Custom Login URL Protection

Source-verified · v2.9.67

For administrators choosing a custom WordPress login entry.

Configure a query-based custom login entry URL and gate direct access to the native login form. WordPress-generated login links use the configured entry, which grants a temporary browser pass to the normal form. Password recovery and necessary API, AJAX and recovery routes are preserved.

In WordPress: PublishRank → Settings → administrator access controls

Know the limits: Optional. WordPress core paths are not renamed. A custom entry changes login behavior; keep strong passwords and two-factor authentication as part of your account security.

08

Redirects & 404 Monitor

Source-verified · v2.9.67

For editors investigating broken links after an article moves or retires.

Redirect Manager supports exact and optional regular-expression rules, bulk import, editing, removal, loop checks, HTTP 301, 302, 303, 307 and 308 redirects, and 410 Gone responses. The separate opt-in 404 Monitor groups requested paths with hit counts, referrers and broad browser/mobile/crawler categories. Dismiss entries, clear logs or create a redirect from a monitored URL.

In WordPress: PublishRank → Redirects; 404 Monitor

Know the limits: Monitoring uses a bounded log of up to 500 paths and does not store visitor IP addresses. Investigate a missing URL before choosing its destination or a Gone response.

09

Robots & AI Discovery

Source-verified · v2.9.67

For owners documenting crawl preferences and curating an AI-oriented content map.

Inspect robots directives with a live preview, crawlability matrix and URL rule tester. Manage sitemap directives, safe custom rules, AI crawler presets and optional WordPress housekeeping. Configure llms.txt with a publication summary, homepage, recent articles, selected pages and editorial standards.

In WordPress: PublishRank → Robots.txt; AI & llms.txt

Know the limits: Robots.txt guides crawlers and does not protect confidential content. llms.txt does not guarantee AI crawling, citation or recommendation.

10

Internal Links & Publisher Toolkit

Source-verified · v2.9.67

For teams maintaining large archives and consistent metadata.

Use locally available Content Graph, inbound-link and focus-keyphrase information to review linking relationships. Bulk edit selected SEO metadata, explicitly clear selected fields and fill missing image alt text when an attachment title is useful. Existing alt text, role checks and per-post edit permissions are respected.

In WordPress: PublishRank → Internal Links; Link Intelligence; Publisher Toolkit

Know the limits: Publisher Link Intelligence does not check external-link availability or send linked URLs to third parties. Review generated alt text for accuracy.

11

Diagnostics & Insights

Source-verified · v2.9.67

For publishers reviewing output, content maintenance and compatibility.

Inspect conflicting SEO plugins, JNews compatibility, frontend metadata, canonicals, schema, sitemap XML and cache diagnostics. Insights flags missing descriptions or images, cornerstone and noindexed articles, and content untouched for at least 180 days. Publisher Analytics provides local 7-, 30- and 90-day SEO-score and IndexNow response trends, SVG graphs, daily tables and CSV export.

In WordPress: PublishRank → Diagnostics; Insights; Analytics; Sitemap Health

Know the limits: Local Publisher Analytics is distinct from Google Analytics and Search Console. Compatibility and operational behavior still require testing on your installation.

12

Search-Engine Integrations

Optional integration · setup required

For owners connecting optional discovery services and read-only search reports.

IndexNow offers manual and automatic publish/update/deletion notifications, individual and bulk actions, key-file checks, exclusions, retry queues and CSV submission history. Optional Baidu submission includes manual and eligible new-content batches with response history. Search Console code includes property selection, clicks, impressions, queries, articles, URL inspection and read-only sitemap status, plus News and Discover totals where available.

In WordPress: PublishRank → Search Console; IndexNow; Search Engines

Know the limits: External setup required. Search Console requests Google webmasters.readonly permission and property access. Broker-based sign-in depends on service readiness; an own-OAuth-client path requires Google Cloud configuration. Neither flow has been live-tested in this audit. IndexNow is not a Google indexing API, and submissions never guarantee indexing.

The foundations around your workflow.

Control title templates and variables, description fallbacks, canonicals, robots metadata, archive noindex settings, Open Graph and X overrides, hreflang, breadcrumbs, resource hints and site verification tags or files. Publisher identity, social profiles and author biography, role and coverage expertise connect to structured data.

The setup wizard, dashboard shortcuts and contextual help support configuration. Settings import/export, validated portability, configuration history, manual snapshots and restoration with a safety snapshot support maintenance. Developers can use hooks, supported REST fields and WP-CLI sitemap status, regeneration and cache-clearing commands. The optional Publisher Account integration is separate from core SEO functionality.
