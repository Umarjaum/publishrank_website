Write and optimize

SEO Score

A local editorial checklist for every story

Scores each article on headline, description, content depth, subheadings, featured image, dates and links, then lists the stories to review first. Scoring runs locally, so article text is not sent to an external service. It is a checklist, not a ranking prediction.

In WordPress: PublishRank → SEO Score

Report an issue with this tool →

Schema

Connected structured data for stories and publisher

Configure publisher identity, article types and media in one place. PublishRank outputs a linked JSON-LD graph with publisher, author, WebSite, WebPage, article, image and breadcrumb entities, with a copyable preview in the editor.

In WordPress: PublishRank → Schema

Report an issue with this tool →

Author Expertise

Show who is behind each story

Keep author details such as role and subject expertise next to your content so bylines and author schema describe real people.

In WordPress: PublishRank → Author Expertise

Internal Links

Find link opportunities and orphan pages

Review inbound links and suggested connections across your archive so older stories keep getting readers and crawlers.

Image Optimizer

Smaller images, consistent social previews

Review image dimensions and file sizes, then create optimized copies with your chosen width, quality and WebP or JPEG output. The original stays on disk. Optional watermarking for social images is separate.

In WordPress: PublishRank → Image Optimizer

Publisher Toolkit

Bulk edits for large archives

Edit selected SEO metadata in bulk, clear chosen fields on purpose, and fill missing image alt text from attachment titles. Existing alt text and edit permissions are respected.

Get discovered

Site Verification

Prove ownership without touching files

Paste the meta tag token from Google, Bing, Yandex, Baidu, Naver, Seznam, Pinterest or Meta, or add any other verification tag. Upload a verification file and PublishRank serves it from your site root. Then test exactly what a crawler sees.

In WordPress: PublishRank → Site Verification

Report an issue with this tool →

Sitemap Health

Check the XML before search engines do

Inspect your sitemap index and Google News sitemap for valid XML, duplicate URLs, child references and counts. The dashboard gives you both URLs to submit.

In WordPress: PublishRank → Sitemap Health

Report an issue with this tool →

Search Console

Optional, read-only search reports

Connect Google Search Console to view search reports inside WordPress. Connecting is optional and core features work without it.

In WordPress: PublishRank → Search Console

Search Engines

Settings for each engine you submit to

Keep the optional discovery services you use in one screen, from verification to submission settings.

In WordPress: PublishRank → Search Engines

IndexNow

Tell participating engines when you publish

Send new and updated URLs to IndexNow and review the submission log. An accepted response means the endpoint acknowledged the request, not that a page was crawled or indexed.

In WordPress: PublishRank → IndexNow

Report an issue with this tool →

Robots.txt

Preview and test crawl rules safely

Inspect directives with a live preview and a URL rule tester. Manage sitemap lines and AI crawler presets. Robots.txt guides crawlers; it does not protect private content.

In WordPress: PublishRank → Robots.txt

Report an issue with this tool →

AI & llms.txt

A curated map of your site for AI agents

Publish a plain Markdown llms.txt with your site summary, homepage, recent articles, pages and editorial standards, plus an optional extended file. It checks the file for problems and shows a preview. It does not grant or deny crawler access.

In WordPress: PublishRank → AI & llms.txt

Report an issue with this tool →

Analytics

Local trends, no visitor tracking

See the editorial score trend, published counts and IndexNow responses over 7, 30 or 90 days, and export the data as CSV. Nothing about visitors or article content goes to a remote analytics service.

In WordPress: PublishRank → Analytics

Report an issue with this tool →

Protect and maintain

Traffic Guard

Allow or block networks and countries

Block IP addresses or CIDR ranges, add trusted exceptions and set country rules through a trusted proxy such as Cloudflare. Administrators, login, REST, feeds, robots.txt, llms.txt and sitemaps are never blocked. Rules run locally and no visitor IP is stored.

In WordPress: PublishRank → Traffic Guard

Report an issue with this tool →

Redirects

Move stories without losing readers

Create exact or regular-expression redirects with 301, 302, 303, 307 and 308 codes or a 410 Gone response, import rules in bulk and check for loops.

In WordPress: PublishRank → Redirects

Report an issue with this tool →

404 Monitor

Learn which missing URLs people request

An opt-in log groups requested paths with hit counts and referrers. Turn any entry into a redirect. IP addresses are not stored.

In WordPress: PublishRank → 404 Monitor

Report an issue with this tool →

Link Intelligence

Audit broken and redirected links

Run an audit for broken internal links, links that pass through redirects and orphan pages, with an optional slower check of external URLs. It uses local analysis and no API.

In WordPress: PublishRank → Link Intelligence
